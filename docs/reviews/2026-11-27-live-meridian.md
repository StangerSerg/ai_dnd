  корней/торпед совпадают с контентом).

1. **DM не повторяет проваленные чеки сам**: r1 dig_roots и revive_terminal провалены
   по дайсам — ход закончен без повторной попытки и без предложения игроку; ретраи
   пришлось задавать скриптом. Цепочки `continue_after` по-прежнему недоиспользуются.
2. **note_fact нестабилен**: r1 пропущен entirely, r2 вызван свободным текстом вместо
   ключа из dm_notes. Для обязательных условий акта это уже закрыто код-гарантией
   victory_facts; повествовательные факты остаются на compliance модели.
3. **Наррация впереди состояния**: r1 «координаты записаны» без note_fact и без
   раскрытого терминала. Подтверждено вторично (первично — magic-world r1 27.11).
