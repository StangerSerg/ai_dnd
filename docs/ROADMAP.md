  календарь растягивается пропорционально.

- Поведение LLM непредсказуемо: итерации промптов (этап 2, 1.8) могут занять больше кода.

## Рекомендация

План — полный SaaS. Естественная точка «стоит ли продолжать» — закрытая бета (этап 3);
сам PLAN говорит «веб только после 1.8». Можно сузить путь: после беты отложить
этапы 5–7 (карта, редакторы, оплата) и сначала обкатать игру с друзьями — тогда
играбельный продукт с реальными игроками за ~2–3 месяца, остальное по мере спроса.
