## Подэтап 4b. Единая механика расходников

**Статус: ЗАПЛАНИРОВАН (23.11, решение пользователя).** Обобщает расходники подэтапа 4
(там `use` = heal/buff/spell) до единой абстракции «расходный материал»: любой предмет

**Модель (триггеры расхода 1 шт.):**
- `use` — зелье/свиток/одноразовый амулет → `consumable_effect` (уже в 4).
- `attack` — стрелы/болты/плазменная торпеда: оружие ссылается на боеприпас

- `throw` — метательный нож/топор: предмет сам оружие, бросок тратит 1 из стека.
- `spend` — запчасти на ремонт, брандер: ведущий/тул тратит N по факту действия.
- Один примитив движка `spend_item(item_id, n)` + проверка остатка до действия;
  одно журнальное событие расхода. Одноразовый амулет = wearable + quantity + `use`.

**Статус: ЗАПЛАНИРОВАН (23.11, решение пользователя).** Посещение покинутой колонии

**Модель (на существующих сущностях):**

- Давление времени («успею до заката?») — нарратив ведущего (read_aloud/dm_notes),
