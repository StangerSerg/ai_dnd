# План внедрения

> Рабочий план по [архитектуре](ARCHITECTURE.md). Выполненный пункт отмечаем `- [x]`.
> Подэтап считается сделанным, когда выполнено его условие **«Готово, когда»**, а не просто отмечены все пункты.

## Как работаем по плану

- Каждый подэтап заканчивается работающим результатом, который можно показать или запустить, и тестами на него.
- Этапы идут по порядку, но подэтапы внутри этапа иногда можно делать в другом порядке, если они не зависят друг от друга.
- **Контрольная точка — подэтап 1.8.** Веб строим только тогда, когда AI DM в консоли играет достаточно хорошо и понятно, сколько стоит ход.
- Новые идеи по ходу работы записываем в раздел «Бэклог» в конце, а не вставляем в текущий этап.
- Ссылки вида «Архитектура: 6.1» указывают на разделы [ARCHITECTURE.md](ARCHITECTURE.md).

- [ ] Переопределение результата и отмена последнего события
- [ ] Трекер инициативы

**Готово, когда:** живой DM проводит сессию демо-сценария без ИИ.

### 4.2 ИИ-помощник DM

- [ ] Кнопка «ИИ: описать»: черновик, правка, отправка
- [ ] Подсказки: реплика NPC, импровизация по ситуации

**Готово, когда:** в гибридном режиме DM получает черновики и отправляет их после правки.

### 4.3 Карта мира

Архитектура: 15.1

- [ ] Карта как проекция журнала событий; неоткрытые точки не отправляются в браузер
- [ ] Отрисовка: пергамент или фон автора, туман, тропа прорисовывается чернилами, фишка отряда
- [ ] Новые локации, придуманные AI DM, появляются рядом с текущей

**Готово, когда:** карта открывается по ходу игры у всех игроков одинаково; в данных браузера нет неоткрытых точек.

### 4.4 «Ход в день»

Архитектура: 5.7

- [ ] Темп `live` / `async`, срок хода, периодическая задача проверки сроков
- [ ] Модуль `notifications`: почта, браузерные push-уведомления, настройки пользователя
- [ ] Напоминания до конца срока; экран «пока вас не было» (`seat_reads`)
- [ ] Не успевшие: пропуск хода или действие ИИ (с разрешения игрока)
- [ ] Групповая инициатива в бою
- [ ] Переключение темпа посреди кампании

**Готово, когда:** тестовая группа неделю играет «ход в день» только по уведомлениям.

**Готово, когда:** собранная в редакторе система, не похожая на 5e (например, 2d6 с частичным успехом), играется с AI DM.

Архитектура: 5.5

**Готово, когда:** один человек проходит сценарий с двумя AI-напарниками; напарники не знают секретов DM.

- [ ] Интерфейс боя: очередь инициативы, кнопки действий, выбор целей

- [ ] Эффекты: криты, провалы, всплывающие цифры урона и лечения

**Готово, когда:** бой из демо-сценария проходится в браузере, один вызов ИИ на раунд.
