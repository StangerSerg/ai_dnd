# Ресев набора правил

Опубликованная версия ruleset обычно неизменяема: обычная команда `seed` не
обновляет уже существующую запись. Ресев — осознанное исключение: он заменяет
`data` указанной существующей версии из `content/rulesets/<id>.json`. Все
сценарии и сессии, ссылающиеся на эту запись, при следующей загрузке правил из
БД получат новые данные; уже загруженные в память экземпляры могут сохранить
старые данные до перезагрузки. Для несовместимых изменений создавайте новую версию.

После проверки нужной базы и содержимого файла из каталога `backend` выполните:

```powershell
uv run ai-dnd-play reseed-ruleset dnd5e-srd@1
```

Используются стандартные настройки `AI_DND_DATABASE_URL` и `AI_DND_CONTENT_DIR`
(или `.env`). Команда проверяет формат и внутреннюю согласованность файла, а
также точное совпадение его id и версии с аргументом. Отсутствующая версия не
создаётся; ошибка в файле или ссылке не меняет БД. Команда обновляет только
`data`, не создаёт версию сценария и не запускает индексацию. Повтор с тем же
файлом безопасен. Новые автоматические тесты ресева отложены до этапа 9.
