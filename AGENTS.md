# Правила работы

- Root — архитектор и тимлид: ставит задачи, проверяет и принимает результаты;
  вся разработка выполняется субагентами.
- Для простых задач назначать `gpt-6.1-terra` с effort `high`, для сложных —
  `gpt-6-sol` с effort `high`.
- Для итогового ревью качества назначать Astra с effort `high`.
- В каждой задаче субагенту указывать цель, файлы, требования, ограничения и
  критерии приёмки. Разграничивать владение файлами параллельных задач.
- Root независимо проверяет каждый результат; найденные ошибки возвращает
  исполнителю на исправление и повторно проверяет перед приёмкой.
- Новую сессию начинать с `docs/HANDOFF.md` и актуального раздела
  `docs/PLAN.md`, затем читать код и документацию адресно. Сохранять контекст,
  решения и фактический статус в проекте для следующих сессий.
- По решению пользователя новые тесты отложены до работающего прототипа.
  Сейчас применять ревью, разовые ручные smoke-проверки, lint и проверку типов;
  фиксировать тестовый долг. Существующие тесты и CI не удалять.
- Не отмечать невыполненные критерии готовности и не публиковать секреты.
