# Магический мир: адаптация к runtime v0.2

Контент `magic-world@1` — адаптация первоисточника к текущему движку; боевые числа, сложности и правила отдыха здесь заданы для прототипа, в исходном описании их нет.

- Единственный класс пакета `magic-world` — `world_mage` («Маг мира»); огонь, воздух и вода доступны сразу, выбирать стихию не требуется.
- Готовый архетип даёт две обычные атаки по одной цели: «Огненная стрела» (огонь) и «Ледяной ветер» (воздух, урон холодом). Обе имеют бонус +5 и урон 1d8+2. Runtime присваивает атакам позиционные ID `attack_1`, `attack_2`: перестановка меняет их соответствие названиям.
- Ледяной щит учтён постоянно как +2 к магической защите, входящие в формулу AC (`13 + dex_mod`, базовая защита 11 плюс щит). Для готового мага при dex 12 это AC 14 (11 + 1 + 2), жизненная сила 27 (26 + con_mod 1). Это не отражение отдельной атаки из первоисточника и не отдельное действие.
- В ядре `RestAction` при полном отдыхе полностью восстанавливает жизненную силу; при коротком отдыхе она не восстанавливается. Это правило адаптации, не правило первоисточника. В текущем игровом интерфейсе и диалоге команды отдыха нет: за фразу о ночлеге жизненная сила не начисляется.
- «Водное лечение» — новая водная форма по решению пользователя от 25.11, через существующий `cast_cure_wounds1`: вне боя сам маг или союзник из отряда, одна цель, 1d8 + модификатор познания магии (для готового мага 1d8+2). По решению пользователя 26.11 количество применений не ограничено, ресурс не расходуется. Без просьбы игрока автоматически не применять. Заклинатель при 0 HP лечить не может; цель при 0 HP поднимается, мёртвых лечение не спасает. Это третья активная форма наряду с двумя атаками; щит — пассивная защита. Внутренний id `cure_wounds` обеспечивает совместимость с существующим обработчиком, маны нет.
- Для создания через веб загружаются значения архетипа `world_mage`, включая обе атаки. Одни только defaults шаблона не содержат атак; потребители шаблона должны подставить архетип или иные допустимые значения атак.
- Изучение и замена форм, общий механизм лимита трёх форм, отдельные механики стихий и массовых заклинаний и мана в этой адаптации не реализованы. Физическое оружие не выдаётся. Полная магическая система остаётся отдельной работой.

Постоянные новые тесты отложены по решению пользователя до работающего прототипа; проверка контента — разовый локальный smoke и ревью.
