# AI DnD Portal — фронтенд-прототип

Автономное локальное демо на Vite, React и TypeScript, без подключения к бэкенду или ИИ. Условный вход не выполняет авторизацию: введённые имя и пароль не отправляются, не сохраняются и не записываются в журнал. Не вводите настоящие учётные данные.

После выбора стола локальный асинхронный `demoSource` предоставляет демонстрационную карточку с параметрами и лимитом очков. Это вымышленные значения, не SRD и не реальные игровые правила. Доступны шесть портретов, роль игрока и отдельная панель живого ведущего. Описание ведущего, действия и демо-команды только добавляют текст в локальную ленту; они не выполняют правил, не связывают игроков и не вызывают ИИ. Все сцены и спутники вымышлены.

Команды ведущего скрываются в режиме игрока только демонстрационной фильтрацией интерфейса; данные остаются в браузере. При реальной интеграции авторизация и фильтрация событий для каждого получателя обязательно должны выполняться сервером.

Персонаж, роль, лента, незавершённые тексты и настройки примера кубика сохраняются в памяти вкладки при переключении экранов и столов, но теряются при обновлении или закрытии страницы. `src/demo.ts` — внутренний презентационный адаптер, не контракт API. При настоящей интеграции проверка правил, вычисления и авторитетное сохранение должны выполняться сервером; формы передают данные и команды, а не определяют результаты игры.

В обоих игровых режимах доступно стилизованное SVG-превью d20 с локально заданными примерами 1, 7 и 20 и косметическими цветами. Оно только отображает готовое значение, не рассчитывает бросок и не является физической 3D-симуляцией. В будущем тип и значение должны поступать с сервера; адаптация API ещё не выполнена, другие виды костей не реализованы.

## Запуск и проверки

Нужен Node.js 20.19+ или 22.12+ (рекомендуется актуальная LTS-версия).

```sh
cd frontend
npm install
npm run dev
```

Откройте адрес, выведенный Vite. Проверки: `npm run lint`, `npm run typecheck`, `npm run build`; просмотр сборки: `npm run preview`. Новые тесты отложены до работающего прототипа; тестовый долг сохраняется.

Фоны входа и зала ожидаются в `public/images/castle-gate.png` и `public/images/great-hall.png`; без файлов используется тёмный фон. Портреты ожидаются в `public/images/avatars/`: `human-knight.png`, `dwarf-cleric.png`, `elf-rogue.png`, `elf-ranger.png`, `human-mage.png`, `dwarf-warrior.png`. При отсутствии портрета показывается текстовое название и запасной символ. Иллюстрации игровых сцен не используются. Шрифты загружаются из Google Fonts; без сети используются системные шрифты.
